极简记账本 Pro - 依赖配置
本应用为纯前端单页面项目，核心文件仅 index.html,无需安装任何 Python 第三方依赖包
两种基础运行方案：
1. 最简方案：直接双击 index.html 文件，使用本地浏览器打开即可正常使用全部功能
2. 本地服务方案：使用 Python 内置静态服务器运行，无需额外安装库，终端执行命令：
python -m http.server 3000
【可选扩展依赖】
若需要功能更强、更稳定的本地静态服务，可手动安装 Flask 框架，版本要求如下
flask>=3.0
补充说明：
前端图表、样式、加密工具均通过 CDN 在线引入，不依赖本地 Python 库；
本文件仅用于项目工程规范化展示，仅当使用 Flask 服务时才需要执行安装命令：
pip install -r requirements.txt
